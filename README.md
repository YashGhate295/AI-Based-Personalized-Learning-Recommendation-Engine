# AI-Based Personalized Learning Recommendation Engine

## Project Overview

This project recommends personalized online courses using a hybrid recommendation approach.

## Features

- Content-Based Filtering
- Collaborative Filtering
- Hybrid Recommendation System
- TF-IDF Vectorization
- Cosine Similarity
- Exploratory Data Analysis
- Course Similarity Heatmap

## Dataset

Coursera Course Dataset

Features:
- Course Name
- University
- Difficulty Level
- Course Rating
- Course Description
- Skills

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn

## Recommendation Techniques

### Content-Based Filtering
Uses:
- Skills
- Difficulty Level
- Course Description

### Collaborative Filtering
Uses simulated user-course interactions.

### Hybrid Model
Combines both approaches for improved recommendations.

## Results

The system generates personalized course recommendations from 3500+ Coursera courses.
